# 崩坏3 · 前文明纪元时间线

> 前文明纪元距今约5万年，是崩坏3世界观中人类文明的第一次纪元。该文明在终焉律者的降临下毁灭，但留下了一系列传承计划，为新文明的诞生奠定了基础。

---

## 📅 时间线

### 早期：崩坏降临与组织成立

| 时间节点 | 事件 | 说明 |
|---------|------|------|
| 前文明纪元初期 | 崩坏现象首次出现 | 崩坏能开始侵蚀人类文明，带来大规模灾难 |
| 崩坏灾难加剧 | **逐火之蛾组织成立** | 人类为对抗崩坏而组建的军事科研组织，集结了最顶尖的科学家与战士 |
| 逐火之蛾成立后 | 第一批律者出现 | 律者作为崩坏的代言人降临，对人类文明造成毁灭性打击 |

### 中期：融合战士计划与律者战争

| 时间节点 | 事件 | 说明 |
|---------|------|------|
| 律者战争期间 | **融合战士计划启动** | 为对抗律者，逐火之蛾将崩坏兽基因注入人类战士体内，创造出超越常人的融合战士 |
| 融合战士计划 | **凯文（Kevin）成为融合战士** | 第一批融合战士，注入崩坏兽基因后获得强大战力，成为人类最强战士之一 |
| 融合战士计划 | **华（Hua）成为融合战士** | 后来成为前文明最强的融合战士之一，擅长剑术 |
| 融合战士计划 | **樱（Sakura）成为融合战士** | 拥有特殊能力的融合战士 |
| 律者战争期间 | **14位律者依次出现** | 每位律者代表一种崩坏的权能，人类逐一对抗并击败他们 |
| 律者战争期间 | **Mei博士（前文明纪元科学家，与雷电芽衣有对应关系）制造神之键** | Mei博士利用律者核心打造出强大的神之键武器，用于对抗崩坏 |
| 律者战争期间 | **苏（Su）参与对抗崩坏** | 后来主导恒沙计划的关键人物 |

### 终末：终焉律者降临

| 时间节点 | 事件 | 说明 |
|---------|------|------|
| 14位律者被击败后 | **第14位律者——终焉律者降临** | 崩坏的最终执行者，拥有毁灭文明的绝对力量 |
| 终焉律者降临 | **前文明被彻底毁灭** | 终焉律者的力量远超融合战士所能抵抗，人类文明走向终结 |
| 文明毁灭前夕 | **传承计划启动** | 人类在最后时刻将希望寄托于未来，启动多个传承方案 |

### 传承计划

| 计划名称 | 主导者 | 内容说明 |
|---------|--------|---------|
| **圣痕计划** | 凯文（Kevin） | 将融合战士的基因与记忆以"圣痕"形式传承给新文明的人类，使其在关键时刻觉醒力量。凯文在新文明苏醒后被苏封印于量子之海约1500年。 |
| **火种计划** | 华（Hua） | 将前文明的知识、技术与记忆保留下来，作为文明复兴的"火种"。华在新文明中苏醒，以赤鸢仙人身份守护神州数千年。 |
| **方舟计划** | — | 寻找新的家园/星球，延续人类文明（最终失联）。 |
| **恒沙计划** | 苏（Su） | 苏使用第二神之键·千界一乘观察宇宙平行世界，寻找对抗崩坏的答案。 |

### 沉睡与等待

| 时间节点 | 事件 | 说明 |
|---------|------|------|
| 文明毁灭后 | **凯文与华进入沉睡** | 凯文在新文明苏醒后建立世界蛇，后被苏封印于量子之海；华以赤鸢仙人身份活动至今 |
| 5万年间 | 沉睡等待 | 前文明的传承计划在暗中运作，圣痕在新文明人类中代代遗传 |
| 约5万年后 | **新文明纪元开始** | 人类再次发展出新的文明，崩坏的威胁也随之回归 |

## 👤 关键人物

### 凯文（Kevin）
- **身份**：前文明融合战士，圣痕计划主导者
- **特点**：人类最强战士之一，拥有超越律者级别的战力
- **命运**：文明毁灭后在新文明苏醒，建立世界蛇组织，试图启动圣痕计划被苏封印于量子之海约1500年后脱出
- **关联**：新文明中的"天命"组织相关人物

### 华（Hua）
- **身份**：前文明融合战士，火种计划主导者
- **特点**：前文明最强的融合战士之一，剑术卓越
- **命运**：文明毁灭后在新文明中苏醒，以赤鸢仙人身份活动于神州，守护人类文明数千年
- **关联**：新文明中与符华（Fu Hua）有直接联系

### 樱（Sakura）
- **身份**：前文明融合战士
- **特点**：拥有特殊能力的融合战士
- **关联**：与新文明中的八重樱有联系

### Mei博士
- **身份**：前文明科学家，神之键制造者
- **特点**：将律者核心转化为神之键武器的天才科学家
- **关联**：新文明中的雷电芽衣（Raiden Mei）与其有前世联系

### 苏（Su）
- **身份**：前文明成员，恒沙计划主导者
- **特点**：通过恒沙计划为新文明培育对抗崩坏的力量
- **命运**：以特殊形式延续存在

## ⚔️ 核心概念

### 融合战士
将崩坏兽基因注入人类体内，使其获得超越常人的战斗力。代价是身体与精神承受巨大负担。凯文、华、樱等均为融合战士。

### 律者
崩坏的代言人，拥有操控特定崩坏权能的力量。前文明共出现14位律者，均被融合战士击败。第14位律者——终焉律者，是毁灭前文明的终极存在。

### 神之键
由Mei博士利用律者核心打造的武器，拥有对抗崩坏的强大力量。在新文明中，神之键成为对抗崩坏的重要武器。

### 终焉律者
崩坏的最终执行者，代表文明终结的力量。终焉律者的降临标志着前文明纪元的终结，是所有传承计划启动的直接原因。
