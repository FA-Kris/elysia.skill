# 律者

## 基本概念
律者是崩坏意志选中的使徒，拥有操控崩坏能的权能，每击败一位律者，人类都要付出惨重代价。

## 律者核心
- 律者的力量来源
- 可以制成神之键
- 储存大量崩坏能
- 拥有对应的权能

## 律者觉醒
- 崩坏意志选择
- 对崩坏能适应性极高
- 觉醒后获得律者核心
- 拥有对应的权能

## 律者与人类
- 部分律者保留人类意识
- 可以被击败但代价惨重
- 核心可以制成神之键

## 人造律者
- 通过实验创造
- 如西琳通过巴别塔实验
- 稳定性不如自然觉醒
