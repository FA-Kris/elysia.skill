## ✦ 角色简介

**爱莉希雅**（Elysia）是《崩坏3》前文明纪元的关键角色。

她**直接诞生自「终焉之茧」**，是前文明最初诞生的律者——官方编号「**第零律者**」，称号「人之律者」「始源之律者」。

> 「某一日，祂从天坠落。人们抬头仰望，于是看见了星空。」
> 「**星月送来神的女儿，她愿成为人的伴侣。**」

崩坏诞生她本是为了毁灭人类，但她在体验了人类世界的一切善恶喜乐之后，**主动选择了平等地爱所有人**。

她是逐火十三英桀**第二位**、刻印「**真我**」，与凯文并称双领袖。凡事任凭心意而为，自由自在，与「第二位」的身份格格不入。

> 「只在喜欢的人上花时间，但每个人都很喜欢；只在有趣的事上花心思，但每件事都很有趣。」

## ✦ 核心设定速览

| 项 | 内容 |
|---|---|
| **刻印** | 「真我」 |
| **英桀位次** | **第二位（Ⅱ）**（官方位次表恒定） |
| **律者编号** | **第零律者**（最初诞生的律者） |
| **融合战士编号** | CM-002（唯一使用「大自在天」基因） |
| **神之键** | 第六神之键·创生之键·**黑渊白花**（初代持有者） |
| **结局** | 由凯文亲手击杀 —— **她主动要求的谢幕** |

### ⚠️ 三个常见误解

1. **她不是「第二律者」** —— 那是空之律者（西琳）。她是**第零律者**，有的是「**第二位**的英桀席位」。
2. **「第十三律者」是伪装** —— 她主动伪造的假身份，用于掩盖真身与死因。
3. **她不是被谋害的** —— 那是**她自己的选择**，为了让残存人类重新团结。
